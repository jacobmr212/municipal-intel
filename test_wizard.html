📋 Manual Test Checklist

Follow these steps in order. Open browser DevTools (F12) → Console tab during testing.

  • Start Assessment: Visit /assessment/anonymous/start, click "Start" on Section 1
  • Test Q1 (Dropdown): Select a state, verify Continue button enables, click Continue
  • Test Q2 (Single-Select Cards): Click an entity type card, verify it highlights, click Continue
  • Test Q3 (Number Input): Enter a population number, verify Continue enables, click Continue
  • Test Transitions: Verify smooth fade-in/fade-out, no flashing between questions
  • Test Progress Bar: Verify progress bar advances after each question
  • Test Save Indicator: After answering a question, look for "Saved" indicator in top-right
  • Test localStorage: In Console, type localStorage, verify you see assessment data saved
  • Test Back Button: Click Back button, verify you return to previous question with answer preserved
  • Test Multi-Select (Q8): Answer questions until you reach Q8 (services), select multiple options, verify Continue enables only when at least one selected
  • Test Resume - Critical Test: Mid-assessment (around Q10), refresh the page (Cmd/Ctrl+R). Verify:
    • You land back on Q10 (not Q1)
    • All previous answers are preserved
    • Progress bar shows correct position
  • Complete Assessment: Continue through all 21 questions to completion
  • Test Completion Redirect: Verify final question redirects you back to assessment dashboard with Section 1 marked "Complete"

🐛 Known Issues to Watch For

  • Auto-advance on any question (all should require Continue button)
  • Flashing/blinking during transitions
  • Continue button enabled when no answer selected
  • Save indicator not appearing after answer
  • Resume not working after refresh (landing on Q1 instead of saved position)
  • localStorage not being updated (check in Console)
